## 快速开始

```bash
# 运行任一模块的测试
python3 01-data-structures/array/dynamic_array.py

# 运行全部测试
find . -name "*.py" -not -name "__init__.py" -not -path "./leetcode/*" \
  -exec python3 {} \;
```

**依赖：** Python 3.9+；数学/ML/DL 模块需 `numpy`，部分示例可选 `matplotlib`、`scipy`、`torch`。

```bash
pip install numpy matplotlib scipy torch --extra-index-url https://download.pytorch.org/whl/cpu
```

## 学习建议

1. **切勿贪多求快**——每个主题务必动手实现核心代码，只看不写等于没学。
2. **交替学习**——数据结构和算法穿插进行，避免长时间卡在同一主题。
3. **定期复习**——用艾宾浩斯复习法，每周末回顾本周内容。
4. **刷题策略**——一道题至少思考 15 分钟再看题解；AC 后务必看讨论区的高赞解法。
5. **项目驱动**——学完 ML/DL 后做一个完整的端到端项目（数据采集→清洗→建模→评估→部署）。
6. **写博客/笔记**——以教代学，把理解到的内容输出出来。

6. **刷题策略**——一道题至少思考 15 分钟再看题解；AC 后务必看讨论区的高赞解法。
7. **项目驱动**——学完 ML/DL 后做一个完整的端到端项目（数据采集→清洗→建模→评估→部署）。
8. **写博客/笔记**——以教代学，把理解到的内容输出出来。
