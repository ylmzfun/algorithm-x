### 6.1 算法设计模式总结

| 模式        | 特征                      | 适用场景                     |
| ----------- | ------------------------- | ---------------------------- |
| 滑动窗口    | 连续子数组/子串问题       | 最长无重复子串、最小覆盖子串 |
| 双指针      | 有序数组、链表问题        | 两数之和 II、三数之和        |
| 快慢指针    | 链表环、中点              | 环形链表、回文链表           |
| 前缀和      | 区间求和                  | 和为 K 的子数组              |
| 单调栈/队列 | 下一个更大/更小、窗口最值 | 接雨水、滑动窗口最大值       |
| 位运算      | 状态压缩、判定奇偶        | 子集枚举、只出现一次的数字   |
| 二分搜索    | 有序序列、单调函数        | 搜索插入位置、二分答案       |
| 拓扑排序    | DAG (有向无环图)          | 课程表、任务调度             |
| 并查集      | 动态连通性                | 朋友圈、岛屿数量             |
| BFS 最短路  | 无权图最短路径            | 单词接龙、迷宫问题           |
| 树形 DP     | 树上决策问题              | 打家劫舍 III、树的直径       |
| 记忆化搜索  | 重叠子问题                | 不同路径、正则匹配           |
